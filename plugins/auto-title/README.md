# 标题自动生成

需要 XTLaw 0.2.0 或更新版本。仅对启用后创建且标题仍为默认标题的新任务，在本轮回答成功结束后生成简短标题。内容不足或标题请求失败时，后续回答结束后可重试。已有任务保留原名。命名不占用主对话工具。

- 在插件设置中选择模型，留空使用任务当前模型。关闭「启用」时，其余设置禁用并保留原值。
- 「允许随任务目标更新」默认关闭；开启后，后续回答完成时，仅在至少有两条用户消息时评估主目标是否明显变化，必要时更新自动标题。每次评估会产生额外模型用量。
- 任务菜单中的「重新生成标题」可为非手动、非 legacy 标题生成标题，不受目标更新所需的两条用户消息门槛限制。
- 手动标题和历史来源不明的标题自动保留。
- 需要读取触发任务的有限消息文本和调用模型的权限；不读取附件内容与工具输出。

生成过程和结果显示在任务历史中，重启后仍可查看；自动跳过不刷屏。

修改输入、切换分支、删除任务或停用插件会使过期调用失效。你在生成期间手动改名时，以手动命名为准。

## 来源与修改

移植自 [useLexora/plugins](https://github.com/useLexora/plugins) 的 `plugins/auto-title`（1.3.0，MIT 许可证）。为适配 XTLaw，只改清单、说明文字和首次命名时机：

- `engines.lexora` 改为 `>=0.2.0 <1.0.0`，按 XTLaw 版本号判断兼容性（任务创建、回合完成等钩子自 XTLaw 0.2.0 起可用）。
- `author` 改为 `XTLaw`。
- `extension.ts` 已与上游 1.3.0 不同：首次命名改为在本轮回答成功结束后执行。中途停止、失败或中断的回合不会触发这次首次命名；内容不足或标题请求失败时，仍可在后续完成回答后重试。
- 本文第一段的版本要求改按 XTLaw 版本号书写。
